# Data and model credits

The three unchanged Montagna CSVs come from Lucia Cavallaro, Annamaria Ficara, Pasquale De Meo, Giacomo Fiumara, Salvatore Catanese, Ovidiu Bagdasar, Wei Song, and Antonio Liotta, *Criminal Network: The Sicilian Mafia. “Montagna Operation”*, version 0.0.1. [Zenodo dataset and citation](https://doi.org/10.5281/zenodo.3938818) · [Companion study](https://doi.org/10.1371/journal.pone.0236476)

The included Casegraph checkpoint fine-tunes the token and NER components of Explosion's English `en_core_web_sm` 3.8.0 pipeline. The original model license and source notices accompany this package. [Original spaCy model release](https://github.com/explosion/spacy-models/releases/tag/en_core_web_sm-3.8.0) · [Model license](third_party/spacy-model-LICENSE.txt) · [Source notices](third_party/spacy-model-LICENSES-SOURCES.txt)

The text reports and annotations shipped with the prototype are fictional examples created for the project. They represent a separate dataset from Montagna.
